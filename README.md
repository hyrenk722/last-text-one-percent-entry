# Last Text at One Percent

The last text message a phone sends at one percent battery, in the voice of the dying phone itself:

> I'm dying at 1% and my only regret is I never got to autocorrect your personality.

## How to run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes the single message (82 characters, one sentence, no trailing newline) to `out/entry.txt`.
